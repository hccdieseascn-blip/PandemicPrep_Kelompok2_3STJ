# PandemicPrep — Kelompok 2
## Pandemic Preparedness: COVID-19 & Emerging Diseases

Website ini mempertahankan template awal dan telah disesuaikan dengan materi Kelompok 2:
1. Global Disease Overview
2. Disease Mapping
3. Prevention Strategy
4. Telehealth Innovation
5. International Communication
6. Reflection

### Menjalankan di VS Code
1. Extract ZIP.
2. Buka folder `pandemic-preparedness` di VS Code.
3. Install extension **Live Server**.
4. Klik kanan `index.html` → **Open with Live Server**.

### Fitur interaktif
- Dark mode
- Responsive navigation
- Scroll/reveal animation
- Interactive Leaflet map (internet diperlukan)
- Tab Prevention Strategy
- Accordion peran pemerintah
- PandemicCare self-screening prototype
- Chatbot edukasi prototype
- Translator demo
- QR Code menuju WHO COVID-19 Dashboard

### Catatan akademik
- Peta dan risk meter bersifat ilustratif, bukan skor resmi.
- Self-screening/chatbot hanya prototype edukasi dan bukan alat diagnosis.
- Data epidemiologi historis mengikuti referensi yang digunakan pada materi tugas.
- Untuk angka terkini, gunakan dashboard resmi WHO/Kemenkes.
- Isi nama/NIM anggota di `MEMBERS.txt` sebelum dikumpulkan.
